Import quiz from JSON

Upload a JSON file to create one Quiz and its Questions. Each question gets Yes/No answers so the existing take-quiz flow works. Yes is marked correct.

This import is text-only. Fields such as section, reference_image_path / image_path, response_type, allow_photo, pages, and requires_photo / photo_required are ignored. Photo-on-fill belongs to Checklists, not Quizzes.

Accepted JSON schema

{
  "name": "Quiz title",          // or "title" or "document"
  "description": "Optional",     // or "notes" or "purpose"
  "items": [                     // or "questions"
    { "text": "Question text" }, // or "title"
    { "title": "Another question" }
  ]
}

Question model: Question.text is 255 characters. Longer titles are truncated. There is no order field; questions are created in file order.
